# `processed/split_meta.yaml` schema

Generated by `notebooks/02_feature_engineering.ipynb` and consumed by dashboard/notebooks.

| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `target_col` | string | yes | Forecast target column (e.g. `target_log_return_1`). |
| `feature_cols` | list[string] | yes | Feature columns for saved models (must not include `target_col`). |
| `ts_col` | string | yes | Timestamp column name. |
| `train_end`, `val_end`, `test_end` | string | yes | ISO dates for split boundaries. |
| `target_horizon` | int | no | Bars ahead for target (default 1). |
| `purged_train_rows`, `purged_val_rows` | int | no | Purged rows at boundaries to prevent leakage. |
| `bar_interval_seconds`, `annualization_factor` | number | no | Bar/volatility scaling context. |

Consumers should ignore unknown keys. Regenerate via notebook 02 after feature changes.
